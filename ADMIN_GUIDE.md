# Sale Bot — инструкция для админа

## 1) Переменные Railway
Обязательные:
- `BOT_TOKEN`
- `CHANNEL_USERNAME` (поддерживаются форматы `@my_channel`, `my_channel`, `https://t.me/my_channel`, `-100...`)
- `ADMIN_IDS` (через запятую: `12345,67890`)

Рекомендуемые:
- `ADMIN_CHAT_ID` (куда бот шлёт уведомления о бронях)
- `TIMEZONE` (по умолчанию `Europe/Belgrade`)
- `SUPPORT_TEXT`
- `PICKUP_TEXT`
- `SLOT_START` (например `09:00`)
- `SLOT_END` (например `21:00`)
- `SLOT_STEP_MINUTES` (например `30`)

## 2) Команды админа
- `/add Название | Цена | Описание | photo_id1|photo_id2`
- `/csv` -> затем отправить CSV файлом
- `/edit <item_id>` -> бот попросит `Название | Цена | Описание`
- `/addphoto <item_id>` -> отправить фото
- `/sold <item_id>`
- `/active <item_id>`
- `/block YYYY-MM-DD HH:MM[,HH:MM] [HH:MM] [причина]`
- `/unblock YYYY-MM-DD HH:MM[,HH:MM] [HH:MM]`
- `/blockday YYYY-MM-DD [причина]`
- `/unblockday YYYY-MM-DD`
- `/slots YYYY-MM-DD`
- `/photoid` (и затем отправить фото, чтобы получить `photo_id`)
- `/version` (текущая ревизия запущенного кода)

## 3) CSV формат
Минимум колонка:
- `title`

Рекомендуемый формат:
- `title,price,description,photos`

Пример:
```csv
title,price,description,photos
Платье Zara,2500 RSD,Новое платье,AgAC...|AgAC...
Ботинки,3000 RSD,Надеты 1 раз,AgAC...
```

`photos` — список `photo_id`, разделитель `|` (также допустимы `,`, `;`, переносы строк).

## 4) Как работает покупатель
- Нажимает в канале `🛒 В корзину`
- Переходит в `/cart`
- Нажимает `✅ Оформить`
- Выбирает день и слот
- Подтверждает бронь
- Получает сообщение с деталями самовывоза

## 5) Критично: как безопасно деплоить в Railway (без дублей)
1. Откройте проект Railway -> сервис бота -> `Settings`.
2. Убедитесь, что подключён **один** GitHub source (одна ветка/репозиторий).
3. Откройте список сервисов проекта и проверьте, что нет второго сервиса с тем же `BOT_TOKEN`.
4. В `Deployments` оставьте активным только один деплой (отмените/удалите дублирующиеся).
5. После этого нажмите `Deploy`/`Redeploy`.

Если в логах есть `TelegramConflictError ... terminated by other getUpdates request`, значит всё ещё запущен второй инстанс с тем же токеном.

## 6) Проверка, что запустилась нужная версия
1. В логах старта найдите строку:
   - `Starting bot revision=<sha>`
2. В Telegram отправьте боту `/version` (от админ-аккаунта).
3. Сравните SHA:
   - если совпадают -> в проде запущен нужный код;
   - если не совпадают -> Railway задеплоил не ту ветку/коммит.

## 7) Smoke-check после деплоя (2 минуты)
1. `/add` с фото в подписи.
2. Проверка кнопки `🛒` — ответ должен прийти покупателю в ЛС, а не в канал.
3. Тест брони -> в канале товар должен стать `🟡 Забронировано`.
4. Тест отмены брони -> товар возвращается в `ACTIVE`, админу приходит уведомление с `@username`.
